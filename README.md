# HH.ru Auto Scroll + Vacancy Opener v1.0

## ✨ Что делает скрипт:

1. **Открывает 1-4 случайные вакансии** на каждой странице поиска
2. **Скроллит каждую вакансию** (8-20 секунд, имитируя чтение)
3. **Возвращается назад** к списку вакансий
4. **Скроллит страницу поиска** до конца
5. **Переходит на следующую страницу** результатов
6. **Повторяет процесс** до достижения лимита

## 🔧 Ключевые особенности:

### SPA (Single Page Application) поддержка
- Использует `MutationObserver` для отслеживания изменений DOM
- Автоматически перезапускается после SPA-навигации
- Не зависает при переходе между страницами

### Персистентное состояние
- Сохраняет прогресс сессии через `GM_setValue/GM_getValue`
- Продолжает работу после перезагрузки страницы
- Отслеживает количество посещённых страниц

### Человекоподобное поведение
- Случайные задержки между действиями
- Случайная скорость скроллинга
- Случайное количество вакансий для открытия (1-4)
- Случайное время "чтения" вакансии (8-20 сек)

## 📊 Логика работы:

### На странице поиска (`/search/vacancy*`):
1. Проверяет, есть ли незавершённые вакансии (после возврата)
2. Если да → продолжает открывать оставшиеся
3. Если нет → выбирает 1-4 новые вакансии случайно
4. Сохраняет URL текущей страницы поиска
5. Открывает первую вакансию из списка

### На странице вакансии (`/vacancy/*`):
1. Скроллит страницу 8-20 секунд
2. Возвращается на сохранённую страницу поиска через `window.location.href`
3. Скрипт перезагружается и продолжает с оставшихся вакансий

### После всех вакансий:
1. Скроллит страницу поиска до конца
2. Кликает "Следующая страница"
3. `MutationObserver` отслеживает изменение DOM
4. Автоматически перезапускает скрипт на новой странице

```javascript

const SESSION_TIME_MAX = 45 * 60 * 1000;  // Макс. время сессии (45 мин)

const PAGE_LIMIT_MIN = 8;                 // Мин. страниц за сессию
const PAGE_LIMIT_MAX = 20;                // Макс. страниц за сессию

const VACANCIES_TO_OPEN_MIN = 1;          // Мин. вакансий на странице

```

## 📈 Индикаторы статуса:

- 🔍 `Selected X vacancies` - Выбрано вакансий для открытия
- 📂 `Opening vacancy X/Y` - Открытие вакансии
- 📄 `On vacancy page` - Находимся на странице вакансии
- 📖 `Reading vacancy...` - Скроллим вакансию
- ⬅️ `Back (X/Y done)` - Возврат к списку
- 📜 `Scrolling to bottom...` - Скролл страницы поиска
- 📄 `Page X/Y` - Переход на следующую страницу
- ⏹️ `Done` - Сессия завершена
